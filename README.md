## Things I've built

**[VaaniPath](https://github.com/sachinkumar2304/vaanipath)** — SIH 2025 winner (team of 6)

A platform that lets a teacher upload a skill-training video once and have it dubbed and subtitled into Indian languages. I worked on the FastAPI backend and the Supabase/PostgreSQL schema: users and roles, courses, enrollments, video processing jobs, quizzes, doubts, reviews, and row-level security policies.

**[FinePulse](https://github.com/sachinkumar2304/FinePulse---BNPL)** — Buy-Now-Pay-Later analytics pipeline

Simulates a BNPL lender end to end. Python generates data (synthetic, using Faker), an ETL pipeline validates it, rejects bad rows with a reason, resolves foreign keys and loads about 510,000 rows into PostgreSQL on Supabase. On top of that: 38 SQL analysis queries, 21 views and a 5-page Power BI dashboard (default rate, outstanding amount, risky merchants, credit-score tiers).

**[Café Delights](https://github.com/sachinkumar2304/Cafe_project)** — cafe ordering system

Next.js + Supabase. Customers order from a menu, admins manage items and orders. Orders are placed through a PostgreSQL function so the order and its items are saved together, and deliveries are confirmed with an OTP.

**[CodeDarpan](https://github.com/sachinkumar2304/CodeDarpan)** — code analysis prototype

FastAPI + React tool that scans a project for dead functions and Hinglish comments, then uses Gemini to write a short summary of the codebase.

**Smaller projects:** [Habit Tracker](https://github.com/sachinkumar2304/habit-tracker) (Django, [live demo](https://habitracker-h4dy.onrender.com)), [Eye-tracking virtual keyboard](https://github.com/sachinkumar2304/eye_detector_project) (OpenCV + MediaPipe), [81 SQL interview questions](https://github.com/sachinkumar2304/SQL_Interview_Questions_Practice) with a practice database for SQL Server.
